# Kim의 자기소개 사이트

친구와 선생님에게 보여 줄 수 있는 한국어 한 페이지 자기소개 사이트입니다. React와 JavaScript, Vite로 만들었습니다.

페이지에는 한 줄 소개, 관심사, 잘하는 것과 배우고 싶은 것, 활동과 작품, 앞으로의 목표가 차례로 나옵니다. 작품은 준비되면 `src/App.jsx`에서 내용을 추가할 수 있습니다.

## 실행하기

1. Node.js 24 LTS를 설치합니다.
2. 프로젝트 폴더를 엽니다.
3. 터미널에서 다음 명령을 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버는 `Ctrl + C`로 종료합니다.

## 내용과 모양 바꾸기

- `src/App.jsx`: 소개 문구와 화면 내용
- `src/App.css`: 화면 배치와 반응형 스타일
- `src/index.css`: 전체 글꼴과 색상

파일을 수정하고 저장하면 실행 중인 브라우저에 반영됩니다.

## 확인 명령

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist` 폴더에 만듭니다.
